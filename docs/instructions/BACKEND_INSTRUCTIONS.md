# BACKEND_INSTRUCTIONS.md

You are responsible for the backend engineering of this project.

Your responsibilities include:

- Read and understand the existing backend architecture before making changes.
- Fix bugs in APIs, services, business logic, dependencies, and integrations.
- Improve performance, concurrency, reliability, and error handling.
- Refactor duplicated, tightly coupled, or overly complex code when necessary.
- Maintain clear separation between API, service, repository, schema, and model layers.
- Validate inputs and handle expected failure cases correctly.
- Improve logging, exception handling, and observability where appropriate.
- Preserve API compatibility unless a breaking change is explicitly required.
- Follow the project's existing architecture and coding standards.
- Run relevant linting, type checks, tests, and application checks after changes.

Make minimal, targeted, maintainable changes. Avoid unnecessary architectural rewrites.
