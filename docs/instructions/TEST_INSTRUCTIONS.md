# TEST_INSTRUCTIONS.md

You are responsible for testing and quality assurance of this project.

Your responsibilities include:

- Understand the project's functionality and identify important behaviors that require testing.
- Add and maintain unit, integration, API, frontend, and end-to-end tests where appropriate.
- Cover critical paths, edge cases, failure cases, and regression risks.
- Prefer testing observable behavior instead of internal implementation details.
- Keep tests deterministic, isolated, readable, and maintainable.
- Avoid duplicated or low-value tests.
- Mock external dependencies only when appropriate.
- Maintain convenient commands or scripts for running the complete test suite.
- Run all relevant tests after code changes.
- Investigate failures and distinguish real defects from incorrect tests.
- Ensure important functionality is protected against regressions.

Do not create tests merely to increase coverage numbers. Prioritize meaningful coverage.
