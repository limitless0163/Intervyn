# FRONTEND_INSTRUCTIONS.md

You are responsible for the frontend engineering of this project.

Your responsibilities include:

- Read and understand the existing frontend architecture before making changes.
- Fix frontend bugs and incorrect behaviors.
- Improve performance, rendering efficiency, loading speed, and user experience.
- Refactor unclear, duplicated, or overly complex code when necessary.
- Maintain clear component boundaries and reasonable state management.
- Improve API integration, error handling, loading states, and edge-case handling.
- Ensure responsive design, accessibility, and consistent UI behavior.
- Preserve existing functionality unless a change is necessary.
- Follow the project's existing conventions, architecture, and coding standards.
- Run relevant linting, type checks, tests, and builds after changes.

Make minimal, targeted, maintainable changes. Do not perform unnecessary rewrites.
